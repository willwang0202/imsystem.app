# iM System

iM System is an unofficial fan project inspired by the in-game social network
"iM" from Rayark's Cytus II. This repository is used only for public issue
tracking and product feedback. It intentionally does not contain the app source
code or implementation notes.

This project is not affiliated with, endorsed by, or guided by Rayark Inc.

Live app: https://imsystem.app or https://www.imsystem.app

## What You Can Do

- Create an account and sign in to the iM-style community feed.
- Share posts with text, images, and hashtags.
- Read post details, reply in comments, and like posts.
- Edit your own posts, comments, profile, avatar, and favorite character accent.
- Browse hashtag pages for related posts.
- Use the interface in English, Traditional Chinese, Simplified Chinese, or
  Japanese.
- Report posts or comments that need moderation.
- Enjoy the iM-inspired visual style, ambient background, and optional music.

## Report an Issue

Use [GitHub Issues](https://github.com/willwang0202/imsystem.app/issues) for:

- Bugs or broken flows.
- UI text, translation, or display problems.
- Accessibility issues.
- Moderation/reporting problems.
- Small feature requests or usability suggestions.

Before opening an issue, please check whether someone has already reported the
same problem.

## Helpful Issue Details

For bug reports, include:

- A short summary of the problem.
- The page or action where it happened.
- Steps to reproduce it.
- What you expected to happen.
- What actually happened.
- Your browser, device, and approximate time of the issue.
- Screenshots or screen recordings, if they help explain the problem.

Do not include passwords, private account details, tokens, or other sensitive
information in public issues.

## Feature Requests

For feature requests, describe:

- The user problem or workflow.
- The change you want to see.
- Why it would improve iM System.
